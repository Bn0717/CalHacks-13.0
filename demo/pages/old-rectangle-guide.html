Snap windows to the side of your screen on a Mac

Posted March 2018 by Jen

Miss Windows' window snapping? The free app Rectangle adds it to your Mac. The fastest way to install it is with Homebrew.

  1. Add the Homebrew Cask tap (you only need to do this once):

    brew tap caskroom/cask

  2. Install Rectangle:

    brew cask install rectangle

  3. Open Rectangle from your Applications folder and allow it in System Preferences › Security & Privacy › Accessibility.

Now press Control + Option + Left Arrow to snap a window to the left half!
