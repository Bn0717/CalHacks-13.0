How do I install wget on my Mac?

Asked by dad_learns_tech · 3 replies

My son's school project says to "use wget" to download some files but my Mac says command not found. I'm not a computer person. What do I do?

macfixer_42 Accepted answer

No worries, it takes two minutes. Open the Terminal app and do this:

  1. First install Homebrew, the free app store for command-line tools (skip this if you already have it):

    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

  2. Then install wget:

    brew install wget

  3. Check it worked. This should print a version number:

    wget --version

That's it! Now wget works in Terminal.
